# 今後の改善課題・Issue (Future Issues)

本ドキュメントは、ひらがな自己対称180度回転アンビグラム生成における構造的課題および、今後実装を検討する発展的アプローチを記録するものです。

---

## 課題の背景: 「の」などにおける剛体回転の限界

平仮名の「の」のように、**外周の円環ループは回転対称に近いが、内側の中央縦棒（始筆部）が中心からオフセットしている文字**では、単なる剛体回転（画像を回転させて平行移動するだけ）を行うと以下のジレンマが生じます：
- 外周を合わせると、中央の縦棒が左右に離れて2本に分裂し、交差（AND）が消失する。
- 中央棒を合わせると、外周ループがズレて楕円の輪郭が重ならなくなる。

現バージョンでは、**「① 座標揺らし探索の拡大 (dx, dy ∈ [-5, 5])」** と **「② 事前太らせ (Pre-Bold: 水平異方性膨張)」** を導入したことで、離れていた縦棒同士を確実に接触・融合させ、力強い一本のストロークとして生成できるようになりました。

さらなる品質向上および極細ストロークでの完全一本化のため、以下の2つの高度なアプローチを将来の課題として記録します。

## Issue #1: 近接ストローク吸引・スナップアルゴリズム (Skeleton Attraction)

- **状態**: 検討中 (Proposed)
- **関連エンジン**: 手法B (`skeleton_engine.py`) / 手法A (`morphology_engine.py`)
- **先行研究**: 魏・山口 (2023)「中心線表現に基づくひらがなアンビグラムの自動生成」

### 概要
正位置文字と180度反転文字の骨格中心線（スケルトン）を抽出し、**一定距離以内にある近接した平行ストローク同士を検出し、中間の回転対称軸に磁石のようにスナップ（吸着・1本化）** させるアルゴリズム。

### アルゴリズム設計案
1. **骨格グラフの抽出**:
   細線化（Zhang-Suen thinning または Medial Axis Transform）により、正位置 $S_1$ と反転位置 $S_2$ の1ピクセル幅の中心線を抽出。
2. **近接平行セグメントのペアリング**:
   距離場 $D(p)$ を走査し、法線方向の距離が閾値 $\epsilon$ (例: 6〜12px) 以内であり、接線方向の成す角がほぼ平行（$\cos \theta \approx 1$）なストローク区間を検出。
3. **引力場 (Attraction Vector Field) の適用**:
   中間線（対称軸） $S_{mid} = \frac{S_1 + S_2}{2}$ を計算し、両ストロークを $S_{mid}$ に向かって引き寄せてマージ。
4. **均一ブラシでの再描画**:
   合体した単一骨格を中心線として、指定線幅の丸筆でストロークを生成。

### 期待される効果
- フォントを太らせることなく、細線ストロークのままでも中央縦棒が完全に1本の美しい中心線に合体する。
- 「き」「さ」の横棒や「む」「す」のループなど、わずかに高さがズレるストローク全般に汎用的に適用可能。

## Issue #2: 非剛体ワープ・局所自由変形エンジン (Non-rigid Morphing / Thin Plate Spline)

- **状態**: 検討中 (Proposed)
- **関連エンジン**: 新手法 / ベクター幾何エンジン (`vector_engine.py`)
- **先行研究**: 石崎ほか (2024)「ひらがな~る: 平仮名の回転対称アンビグラム自動生成」

### 概要
文字を硬い板（剛体）として回転・平行移動するのではなく、**ゴム膜のように局所的に微小変形（Non-rigid Warping）** させることで、外周の一致を維持したまま中央棒だけを中心対称軸へ数ピクセル曲げて完全一致させる手法。

### アルゴリズム設計案
1. **特徴制御点 (Control Points) の配置**:
   - **固定境界点 (Fixed Anchors)**: 外周ループなど、すでに正反で高度に一致している輪郭線上には「変位ゼロ」のアンカーを配置。
   - **変位制御点 (Target Displacement Points)**: 中央縦棒の端点・屈曲点に制御点を置き、180度反転文字の対応点との中間地点への変位ベクトル $\vec{v}$ を設定。
2. **薄板スプライン (Thin Plate Spline: TPS) 変形**:
   曲げエネルギー最小化問題を解き、文字グリフ全体のスムーズな変形場 $f(x, y)$ を算出。
3. **グリフの局所ワープ**:
   変形場を適用してストロークをわずかに歪ませた状態で正反の合成を行う。

### 期待される効果
- 外周のループ形状（真円・楕円）を1ミリも崩すことなく、内側の中央棒だけを完全に重なり合う位置に誘導できる。
- タイポグラフィとして最も自然でプロのデザイナーが手書きしたかのような有機的なアンビグラムが自動生成可能。
