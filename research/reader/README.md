# アンビグラム研究 論文・コード解読リーダー (Paper & Code Inspector)

学術論文の理論 (数理・画像処理・機械学習) と、本システム (`ambigram-maker`) のコード実装を双方向で結びつけて理解するためのインタラクティブ読解ツールです。

---

## 起動方法

ブラウザで直接開くだけで動作します (サーバー不要・完全オフライン対応)。

| 実行環境 | 起動コマンド | 備考 |
|:---|:---|:---|
| Windows (PowerShell) | `start research/reader/index.html` | デフォルトブラウザで直接開く |
| macOS | `open research/reader/index.html` | Safari/Chrome等で開く |
| Linux | `xdg-open research/reader/index.html` | 規定のブラウザで開く |

---

## コード変更に対する自動同期 (sync_code.py)

ベースコード (`backend/`) に変更やリファクタリングが入った場合でも、以下のスクリプトを実行するだけで、コード解説用のデータ (`code_content.js`) が最新の関数シグネチャ・Docstring・行番号で自動更新されます。ドキュメントの陳腐化や手動コピペの二重管理を防ぎます。

```bash
python research/reader/sync_code.py
```

## 主な機能

1. **インライン・アノテーション & 浮動ツールチップ**:
   - 難解な専門用語・数式にカーソルを合わせると、思考を止めずに1〜2行で直感的にわかる要約ポップアップを表示。
2. **右ペイン・インスペクター**:
   - 用語をクリックすると、右パネルに「直感的な解説」と「論文内での役割・選定理由」を展開。
3. **本アプリ実装コードとの連動 (Code Mapping)**:
   - 各理論が `ambigram-maker` (`backend/scoring/`, `backend/generators/`, `backend/evaluation/`) のどのファイル・関数・数式として実装されているかをコードスニペット付きで提示。
   - 上部ヘッダーの「実装対応のみ」ボタンで、コードと繋がっている用語だけを抽出ハイライト可能。
4. **読解進捗・理解度チェック**:
   - 「習得済みにする」ボタンをクリックすると、ブラウザの `localStorage` に記録され、ヘッダーの進捗バッジ (例: `習得 5/14`) に反映。
5. **コンテンツ切り替え**:
   - 上部タブで論文05、論文02、アプリ実装コードを瞬時に切り替え可能。
